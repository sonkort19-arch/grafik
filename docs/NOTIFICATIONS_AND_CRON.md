# МА График: автоматические проверки и push

## Что работает на сервере

Supabase `pg_cron` запускает `ma-shifts` каждые пять минут. `pg_net` отправляет запрос `{"op":"cron-check"}`. Секрет создаётся случайно и хранится только в Supabase Vault. Проверка секрета доступна только роли `service_role`. Доступный владельцу запрос `scheduler-status` показывает время последней успешной проверки и количество активных push-подписок, не раскрывая ключи.

Сервис проверяет опоздание при открытии и досрочное закрытие смены. Если точка не открыта через десять минут после начала или не закрыта через пятнадцать минут после окончания, уведомление отправляется владельцу. Сотрудникам напоминания отправляются вечером предыдущего дня, за час и за пятнадцать минут до начала смены. Неподтверждённые отправки не учитываются как доставленные и повторяются в соответствующем временном окне.

## Как включить уведомления на iPhone

1. В Safari откройте https://grafik-umber.vercel.app/ и добавьте приложение на экран «Домой». Запустите установленное приложение.
2. Владелец: войдите администратором, откройте «Настройки» → «Уведомления владельцу» и нажмите «Включить уведомления». Подтвердите системный запрос и дождитесь тестового уведомления.
3. Сотрудник: выберите себя, нажмите «Включить напоминания» и введите личный PIN. Если PIN не назначен, владелец должен создать его в разделе «Настройки» → «PIN-коды». Смена мастерского PIN для напоминаний не предоставляет право открывать смены.
4. Если устройство раньше было подписано, но серверная подписка стала неактивной, нажмите включение ещё раз. Приложение автоматически пересоздаст подписку, если старый адрес отклонён push-сервером.

Приложение не может включить уведомления на чужом устройстве без его разрешения.

## Проверка планировщика

В настройках администратора отображаются время последнего выполнения, доступность отправки Web Push и количество активных телефонов. При отсутствии успешного запуска более двенадцати минут показывается предупреждение.

Проверки на сервере (не выводите Vault-секрет в SQL-результат):

```sql
select jobid, jobname, schedule, active
from cron.job
where jobname = 'ma-grafik-shift-check-every-5-minutes';

select executed_at, summary
from public.ma_grafik_cron_runs
order by executed_at desc
limit 10;

select runid, status, return_message, start_time, end_time
from cron.job_run_details
where jobid = (
  select jobid from cron.job
  where jobname = 'ma-grafik-shift-check-every-5-minutes'
)
order by start_time desc
limit 10;
```

Если cron-ошибки связаны с HTTP, проверьте `net._http_response` и логи функции `ma-shifts`. Если push не доставляется, проверьте подписку непосредственно на телефоне. Устаревшие push-адреса после HTTP 404/410 отключаются.

## Откат

Чтобы временно остановить проверки, выполните `select cron.unschedule('ma-grafik-shift-check-every-5-minutes');`. Для возврата старой версии функции можно развернуть `ma-shifts` из коммита перед этим исправлением. Не удаляйте таблицы истории смен, подписки и ключи Vault при откате; они не требуют изменения.
